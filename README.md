# .github

Organization-wide files for idk-roblox-project:

- `profile/README.md`: the public organization profile shown on github.com/idk-roblox-project
- `CONTRIBUTING.md`, `pull_request_template.md`, `ISSUE_TEMPLATE/`: defaults for every repository that doesn't have its own

This repository is public so that GitHub can show the profile and apply the defaults. Don't put anything private here.
